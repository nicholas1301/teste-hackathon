# Teste Hackathon

Uma página inicial estática (`index.html`) com acesso aos dois simuladores, um visualizador 3D do Sistema Solar (`solar.html`) e um visualizador 3D da Terra (`terra.html`), sem dependências nem etapa de build. Abra os arquivos em um navegador para visualizar.

O deploy no GitHub Pages é feito automaticamente a cada push para `main`.

- Site: https://nicholas1301.github.io/teste-hackathon/
- Repositório: https://github.com/nicholas1301/teste-hackathon
