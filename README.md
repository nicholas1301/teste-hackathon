# Teste Hackathon

Uma página inicial estática (`index.html`) com acesso a três ferramentas: um visualizador 3D do Sistema Solar (`solar.html`), um visualizador 3D da Terra (`terra.html`) e o Health Monitoring Dashboard (`saude.html`), um painel de monitoramento de saúde para astronautas (conforme `spec.md`), sem dependências nem etapa de build. Abra os arquivos em um navegador para visualizar.

O deploy no GitHub Pages é feito automaticamente a cada push para `main`.

- Repositório: https://github.com/nicholas1301/teste-hackathon
